# 媒体工具里程碑

## M0：规格与环境基线

范围：完成规格包、确认 FFmpeg 版本、确认 S3/本地存储策略、确认 Celery 队列和功能开关。

退出条件：文档完整；开发环境能执行 FFmpeg/FFprobe；不改线上数据；安全检查无新增密钥。

演示资产：能力列表、架构图、FFmpeg 探针输出。

## M1：P0 文件与任务基础

范围：媒体文件表、任务表、事件表、上传探测、任务查询、权限隔离、清理任务。

退出条件：上传有效/无效文件均有明确结果；刷新页面可查询任务；用户之间无法越权；pytest 集成测试通过。

演示资产：上传页面录屏、任务状态 API 样例、迁移验证记录。

## M2：P0 转换能力

范围：格式转换、压缩、截取、提取音频、音频转换，复用项目1格式和编码器规则。

退出条件：MP4/WEBM/MKV 转换、MP4 转 MP3、WAV 转 MP3、压缩和截取样例通过；成功率和失败码可统计。

演示资产：五个工具页面和端到端下载流程。

## M3：P1 视频增强工具

范围：合并、GIF、截图、尺寸调整、旋转、静音、水印和区域隐私处理。

退出条件：每个工具有独立参数模型、任务类型、权限和回归样例；复杂水印不影响基础转换。

演示资产：合并、GIF、水印和模糊处理样例。

## M4：平台化与运营

范围：批量任务、任务取消/重试、历史筛选、管理员聚合指标、存储成本和会员策略。

退出条件：开关、告警、清理、负载测试和回滚演练完成；线上分阶段放量。

演示资产：运营看板、告警演练记录、发布回滚记录。
