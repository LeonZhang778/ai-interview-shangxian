## 三、已发现的 P0 缺陷与修复方案

### 缺陷 1: 视频合并 (merge) — 只传单个文件

**问题描述：**
前端 `MediaTools.vue` 的 merge 工具只允许选择单个文件，但合并至少需要2个文件。

**当前代码（错误）：**
```js
// MediaTools.vue — 提交时只传一个 file_id
if (selectedTool.value === 'merge') {
  await createMergeTask({ ...payload, file_ids: [selectedFile.value.id] })
}
```

**后端校验（正确但无法到达）：**
```python
# tasks.py — _validate_special_options
if len(file_ids) < 2 or len(file_ids) > 10:
    raise APIException(code=10401, message="视频合并至少需要2个、最多10个文件")
```

**项目1 的正确做法 (`VideoMerge.vue`):**
- 支持多文件选择：拖拽 + 对话框批量选择
- 文件列表排序：上移/下移按钮，调整合并顺序
- 每文件展示：缩略图、文件名、格式、分辨率、时长
- 后端 `runWebMergeTask` 实现：
  1. 逐个转码为 mpegts（统一编码/分辨率）
  2. 使用 `concat:` 协议合并
  3. 输出最终格式

**修复方案：**
1. 前端 `MediaTools.vue` 的 merge 工具改为多文件选择模式
2. 添加文件排序 UI（上移/下移按钮）
3. 文件列表展示每个文件的缩略图、时长、分辨率
4. 后端 `merge` 接口已支持 `file_ids` 数组，但需确保文件属于同一用户
5. 需要添加重复文件检测

### 缺陷 2: 视频水印 (watermark) — 缺少文字水印/去水印

**问题描述：**
前端只支持图片水印，缺少文字水印；水印参数只有位置/透明度，缺少时间控制/预览/去水印。

**当前代码（简陋）：**
```js

// 提交时只传：
// - file_id
// - watermark_file_id（图片ID）
// - position（位置枚举）
// - opacity（透明度）
// - watermark_width（水印宽度）
```

**项目1 的完整水印功能 (`VideoWatermark.vue`, 1100行):**

**水印类型：**
- **图片水印（image）**：上传 PNG/JPG/WebP，可调缩放比例
- **文字水印（text）**：输入文字，可选字体、字号、粗体/斜体/下划线

**位置控制：**
- **自定义拖动**：在视频预览上自由拖拽水印位置
- **平铺 (tile)**：水印在视频上平铺排列
- **九宫格 (grid)**：3×3 网格排列
- 支持旋转（-180°~180°）

**时间控制：**
- 水印显示的开始时间和结束时间
- 精确到帧级别的时间轴

**预览：**
- 视频播放器实时预览水印效果
- 播放/暂停/进度条控制
- 坐标转换：预览坐标 → 实际视频坐标

**去水印 (remove-watermark)：**
- 框选要去除的区域
- 支持多区域选择
- 两种模式：模糊（blur）和颜色填充（fill）
- 区域可拖动调整位置和大小

**后端实现 (`server/index.ts`):**
- 文字水印：生成 ASS 字幕文件 → 通过 `ass` filter 渲染
- 图片水印：`overlay` filter + 多位置组合
- 去水印：`delogo`/`boxblur` complex filter 或 `drawbox`

**修复方案：**

2. 新增文字水印编辑器（字体、字号、样式）

当前项目 `format_config.py` 已蒸馏了部分内容，但水印相关参数矩阵缺失。

### 5.2 水印处理流程

**图片水印 (overlay + complex filter):**
```
1. 上传水印图片 → /api/upload-watermark-image
2. 创建水印任务 → /api/add-watermark
3. 后端处理：
   a. 解析水印数组（支持图片+文字混合）
   b. 文字水印 → 生成 ASS 字幕文件
   c. 图片水印 → 缩放 + 定位 + overlay
   d. 组合 complex filter 链
   e. 执行 FFmpeg 命令
4. 生成输出文件 + 下载链接
```

**去水印 (delogo/drawbox):**
```
1. 用户框选区域（x, y, width, height）
2. 两种模式：
   - blur: split → crop+boxblur → overlay
   - fill: drawbox 填充颜色
3. 支持多区域组合
```

### 5.3 视频合并流程

```
1. 每个输入文件 → 转码为 mpegts（统一编码/分辨率/帧率）
2. 使用 concat 协议合并所有 TS 文件
3. 输出最终格式

关键参数：
- 分辨率统一：scale + pad（保持宽高比）
- 帧率统一：-r 30
- 音频统一：-ar 44100 -ac 2
```

## 七、关键技术参考

### 7.1 FFmpeg 水印命令

**文字水印 (drawtext):**
```bash
ffmpeg -i input.mp4 -vf "drawtext=fontcolor=white@0.8:fontsize=24:x=10:y=10:text='水印文字':enable='between(t,0,30)'" output.mp4
```

**图片水印 (overlay):**
```bash
ffmpeg -i input.mp4 -i watermark.png -filter_complex "[0:v][1:v]overlay=10:10:enable='between(t,0,30)'" output.mp4
```

**去水印-模糊 (delogo+boxblur):**
```bash
ffmpeg -i input.mp4 -filter_complex "[0:v]split=2[base][crop_input];[crop_input]crop=w=100:h=50:x=10:y=10,boxblur=10:1[blur];[base][blur]overlay=10:10[output]" -map "[output]" -map 0:a output.mp4
```

**去水印-填充 (drawbox):**
```bash
ffmpeg -i input.mp4 -vf "drawbox=x=10:y=10:w=100:h=50:color=black:t=fill" output.mp4
```

### 7.2 视频合并

```bash
# 1. 每个输入转码为 TS
ffmpeg -i input1.mp4 -vf "scale=1920:1080:force_original_aspect_ratio=decrease,pad=1920:1080:(ow-iw)/2:(oh-ih)/2,setsar=1" -r 30 -ar 44100 -ac 2 -bsf:v h264_mp4toannexb -f mpegts part_1.ts

# 2. concat 合并
ffmpeg -i "concat:part_1.ts|part_2.ts|part_3.ts" -f mpegts -c copy output.mp4
```

### 7.3 ASS 字幕文件格式（文字水印关键）

```
[Script Info]

[V4+ Styles]

[Events]
Format: Layer, Start, End, Style, Text
Dialogue: 10,0:00:00.00,0:00:30.00,WM0,,{\an7\pos(10,10)}水印文字
```

## 八、注意事项

1. **语言差异**：项目1 后端是 TypeScript → Node.js → fluent-ffmpeg，当前项目是 Python → FastAPI → subprocess FFmpeg。FFmpeg 命令参数可直接复用，但进程管理方式不同。
2. **任务队列**：当前项目使用 Celery 异步处理，项目1 是同步阻塞轮询。水印处理需要确保 Celery worker 能访问上传的文件。
3. **文件存储**：项目1 使用本地文件系统，当前项目也是本地文件系统，但生产环境需要 S3 兼容的存储。
4. **用户认证**：当前项目使用 JWT，项目1 使用 OAuth + Token。API 参数传递方式不同。
5. **前端组件库**：项目1 使用 Element Plus，当前项目是自定义 CSS。UI 组件需要重新实现样式。
