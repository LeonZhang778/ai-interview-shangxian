# 媒体工具风险登记

| 风险 | 触发信号 | 影响 | 缓解措施 | Owner |
|---|---|---|---|---|
| FFmpeg 未安装或版本不兼容 | 启动探针失败、任务集中失败 | P0 不可用 | 镜像内安装并锁版本，启动检查，保留版本白名单 | 后端/运维 |
| 大文件耗尽磁盘 | 磁盘 >80% | 其他业务受影响 | 配额、大小限制、过期清理、磁盘告警 | 运维 |
| 任务状态丢失 | Redis/worker 重启 | 用户看不到结果 | PostgreSQL 持久记录、幂等任务、恢复扫描 | 后端 |
| 路径穿越或越权下载 | 安全扫描或异常访问 | 数据泄露 | 只用 file_id/task_id，查询带 user_id，短期签名 URL | 安全/后端 |
| FFmpeg 参数注入 | 异常参数或命令错误 | 任意命令/任务失败 | Pydantic 范围校验、枚举白名单、禁止 shell 字符 | 后端 |
| 编码器兼容性不足 | 特定格式失败率升高 | 用户转换失败 | 复用项目1兼容矩阵，维护样例文件回归集 | 后端 |
| S3 服务故障 | 上传失败率 >5% | 任务无法完成 | 重试、暂存策略、开关关闭新任务 | 运维 |
| 水印字体缺失 | 中文水印乱码 | 功能质量下降 | 镜像安装字体、字体白名单、样例验收 | 后端 |
| 任务并发过高 | CPU/内存持续 >85% | API/worker不稳定 | 队列限流、每 worker 单进程、会员并发策略 | 运维 |
| 用户误解“去水印” | 投诉或失败率高 | 产品风险 | 对外命名为模糊/遮挡，不宣传 AI 修复 | 产品 |
| 源项目密钥泄露 | Git/日志出现凭据 | 账号或资源被盗 | 轮换密钥、环境变量、历史扫描 | 安全 |
