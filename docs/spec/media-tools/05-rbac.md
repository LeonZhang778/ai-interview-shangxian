# 媒体工具权限矩阵

## 1. 角色定义

- 游客：未登录访问者，只能查看能力列表和公开说明。
- 普通用户：已登录的基础用户。
- 会员用户：已登录且通过当前平台会员策略校验的用户。
- 管理员：当前项目后台管理员。

## 3. 属性约束

- 所有用户级资源查询必须同时使用 `current_user.id` 和资源 ID。
- 管理员查看任务只返回元数据、状态和错误聚合，默认不返回下载地址。
- 普通用户的文件大小、并发数、工具范围和保留时间由平台配置控制。
- 会员权限只能通过当前项目的用户/会员服务判断，不调用源项目 OAuth 或远程会员接口。
- 任务取消只能作用于当前用户且状态为 `queued` 或 `processing`。
- 下载地址必须短期有效，且生成时再次校验用户所有权和任务状态。
