# 媒体工具用户故事

## STORY-003：合并和 GIF 工具

### Story

作为用户，我希望将多段视频合并或制作成 GIF，以便快速制作可分享内容。

### 关联需求

REQ-MEDIA-009。

### 验收标准

```gherkin
场景: 合并两个有效视频
  假设 用户选择两个有效视频并完成排序
  当 用户提交合并
  那么 系统统一必要的媒体参数并执行任务
  并且 输出视频可下载

场景: 合并包含损坏文件
  假设 输入列表中有一个无法探测的文件
  当 用户提交合并
  那么 系统拒绝任务并指出无效文件
  并且 不生成半成品

场景: 生成短 GIF
  假设 用户选择视频片段、宽度和 FPS
  当 用户提交 GIF 任务
  那么 系统限制时长和尺寸后执行
  并且 完成后提供 GIF 下载
```

### UX 与遥测

多文件列表支持排序、删除和空状态；发送任务创建、完成和失败事件。

### 依赖与复杂度

依赖合并参数统一、GIF palette 策略、临时目录清理。复杂度：XL。

### DoD

完成格式样例回归、长视频限制、并发控制和产物清理测试。
