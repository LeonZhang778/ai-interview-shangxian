# 媒体工具用户故事

## STORY-004：水印和隐私处理

### Story

作为用户，我希望给视频添加水印或遮挡敏感区域，以便发布时保护版权和隐私。

### 关联需求

REQ-MEDIA-009。

### 验收标准

```gherkin
场景: 添加文字水印
  假设 用户上传有效视频并填写文字、位置和透明度
  当 用户提交水印任务
  那么 输出视频包含指定水印
  并且 结果可下载

场景: 水印参数越界
  假设 透明度大于 100 或坐标为负数
  当 用户提交任务
  那么 系统返回 media_option_invalid
  并且 不创建 worker 任务

场景: 区域模糊
  假设 用户提供合法矩形区域并选择 blur
  当 用户提交隐私处理任务
  那么 指定区域被模糊
  并且 系统不把该功能描述为 AI 去水印
```

### UX 与遥测

水印页面支持预览参数但不要求前端实现媒体渲染；区域处理页面明确提示范围和效果限制。

### 依赖与复杂度

依赖水印 Schema、ASS/overlay 构建、字体和 FFmpeg 过滤器。复杂度：XL。

### DoD

中文字体、透明度、时间范围、图片水印、模糊和颜色遮挡均有样例测试。
