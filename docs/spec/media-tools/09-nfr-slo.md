# 媒体工具非功能需求与 SLO

## 1. 可用性与性能

- API 月可用性目标：99.5%。
- 上传初始化接口 p95 <500ms，不包含文件传输时间。
- 任务查询接口 p95 <300ms。
- 下载地址生成 p95 <500ms。
- 单个 worker 默认并发 1 个 FFmpeg 进程，按 CPU 和内存压测后调整。
- 单任务最长处理时间 2 小时，超时进入 failed 并清理。

## 2. 安全

- 只接受扩展名、MIME 和 FFprobe 均通过的文件。
- 目标格式、编码器、分辨率、帧率、区域坐标全部白名单和范围校验。
- 不接受前端物理路径，不拼接未经校验的 shell 命令。
- 下载必须校验用户、任务状态和过期时间。
- 临时文件权限最小化，结果 URL 短期有效。
- 不记录密钥、Cookie、Bearer token、签名 URL 和用户文件内容。
- FFmpeg 进程使用超时、资源限制和独立临时目录。

## 3. 可访问性

- 所有文件输入、参数输入和进度区域有可读标签。
- 键盘可完成上传、参数填写、提交、取消和下载。
- 状态不仅使用颜色表示，必须有文本和可访问名称。
- 进度使用 `role=progressbar` 并提供当前百分比。

## 4. 国际化与数据保留

- API 错误码稳定，前端文案可国际化；首期中文。
- 原始文件默认保留 3 天，结果文件默认保留 3 天，会员策略可配置。
- 任务记录保留 90 天用于统计和排障，删除文件不删除聚合指标。

## 5. 兼容性

- 支持现代 Chromium、Firefox、Safari 最新两个大版本。
- 服务端优先支持 Linux 系统 FFmpeg；开发环境提供版本探针。
- 输出文件名必须安全化，不能包含路径分隔符或控制字符。
