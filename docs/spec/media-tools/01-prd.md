# 媒体工具模块产品需求文档

## 1. 产品定位

在已上线的综合工具平台中增加独立的“视频与音频工具”能力，复用项目1的成熟媒体处理规则，同时统一接入当前平台的用户、存储、任务、权限和管理体系。用户无需理解 FFmpeg 参数即可完成常见媒体处理，也可以在高级模式中控制格式、编码器、码率、分辨率和时间范围。

## 2. 用户问题

- 视频格式不兼容，无法上传、播放或分享。
- 视频文件过大，超出邮箱、平台或网盘限制。
- 需要从视频提取音频，或将音频转换为指定格式。
- 多段视频需要拼接，短片段需要转 GIF。
- 发布视频前需要添加文字/图片水印或遮挡敏感区域。
- 现有工具分散，处理过程缺少进度、历史和可恢复结果。

## 3. 目标与指标

### 产品目标

- 提供稳定的 Web 视频、音频通用工具入口。
- 让普通用户在三步内完成一次单文件转换。
- 将重 CPU 处理从 API 进程移到 Celery worker。
- 统一文件生命周期、任务历史、下载和清理能力。
- 支持后续图片、PDF、文本工具复用同一工具平台框架。

### 首期指标

- 单文件转换成功率不低于 97%。
- 任务状态接口 p95 小于 300ms。
- 95% 的普通 MP4 转 MP4 任务在 30 秒内进入 processing 状态。
- 上传、处理、下载全链路错误可追踪率达到 99%。
- 过期临时文件清理成功率不低于 99%。

## 4. 功能范围

### P0

- 媒体上传与 FFprobe 检测。
- 视频格式转换。
- 视频压缩。
- 视频截取。
- 视频提取音频。
- 音频格式转换。
- 任务进度、取消、失败重试。
- 结果下载和任务历史。
- 用户文件隔离和自动清理。

### P1

- 多视频合并。
- 视频转 GIF。
- 视频截图。
- 视频尺寸调整、旋转、翻转、静音。
- 文字水印和图片水印。
- 视频区域模糊与颜色遮挡。
- 批量转换。

### 非本期

- AI 自动识别人脸或车牌并跟踪打码。
- 真正的 AI 去水印内容修复。
- 在线多人协同编辑。
- 源项目 OAuth、会员支付和 Electron 桌面端迁移。

## 5. 需求编号

- REQ-MEDIA-001：用户可以上传受支持的视频或音频文件，并获得媒体元数据。
- REQ-MEDIA-002：用户可以提交单文件格式转换任务。
- REQ-MEDIA-003：用户可以提交压缩、截取、提取音频和音频转换任务。
- REQ-MEDIA-004：系统必须显示任务阶段、进度和最终结果。
- REQ-MEDIA-005：任务只能访问当前用户拥有的文件。
- REQ-MEDIA-006：处理失败必须保留可读错误并支持安全重试。
- REQ-MEDIA-007：系统必须自动清理过期源文件、临时文件和结果文件。
- REQ-MEDIA-008：管理员可以查看任务指标和失败原因，但默认不能下载用户内容。
- REQ-MEDIA-009：P1 支持合并、GIF、水印和区域隐私处理。
- REQ-MEDIA-010：媒体模块必须能够被未来图片、PDF工具复用。

## 6. 用户角色

- 游客：可查看工具介绍和格式支持，不创建处理任务。
- 普通用户：上传文件、创建 P0 任务、查看自己的历史和下载结果。
- 会员用户：享受更大文件、更高并发和 P1 能力，具体额度由平台配置决定。
- 管理员：查看聚合指标、失败任务和配置开关，不默认读取用户文件内容。

## 7. 成功标准

当用户可以在主站登录后完成“上传 MP4 → 选择 MP3 → 提交 → 查看进度 → 下载结果”的完整流程，任务记录可在刷新页面后恢复，错误任务可重试，过期文件不会长期占用存储，即视为 P0 验收通过。
