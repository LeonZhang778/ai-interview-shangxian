## 优先级说明

```
P0 (体验基线) → 用户能正常使用，体验不粗糙
  └─ P1 (AI 差异化) → 发挥 AI 面试平台优势，形成竞争壁垒
      └─ P2 (增强体验) → 社区氛围和留存抓手
```

建议按文档编号顺序迭代开发，每个文档独立可交付。
