# P2 · 笔记模板

> 优先级：P2 | 预估工时：1-1.5 天 | 涉及端：后端 + 前端

---

## 1. 背景与目标

### 当前问题
- 新建笔记时是空白输入框，不知道写什么
- 用户需要结构化地记录面试复盘、错题分析等
- 缺少模板降低创作门槛

### 目标
- 提供 4 种预设模板：面试复盘 / 错题分析 / 面经整理 / 知识笔记
- 新建笔记时可选模板，快速填充结构
- 模板内容为 Markdown 骨架，用户直接编辑完善

def get_templates() -> List[Dict]:
    """获取所有模板列表（不含正文，用于前端选择器）"""
    return [
        {
            "id": t.id,
            "name": t.name,
            "description": t.description,
            "icon": t.icon,
            "note_type": t.note_type,
        }
        for t in TEMPLATES.values()
    ]


def get_template(template_id: str) -> NoteTemplate | None:
    """获取单个模板"""
    return TEMPLATES.get(template_id)

## 3. 后端 API

**文件：`app/api/client/v1/note_template.py`**（新增）

```python
from fastapi import APIRouter
from app.schemas.response import ApiResponse

router = APIRouter()


@router.get("/templates")
async def get_note_templates():
    """获取所有笔记模板"""
    from app.services.client.note_template import get_templates
    return ApiResponse.success(data={"templates": get_templates()})


@router.get("/templates/{template_id}")
async def get_template_detail(template_id: str):
    """获取模板详情（含 Markdown 正文）"""
    from app.services.client.note_template import get_template
    t = get_template(template_id)
    if not t:
        return ApiResponse.error(message="模板不存在")
    return ApiResponse.success(data={
        "id": t.id,
        "name": t.name,
        "description": t.description,
        "icon": t.icon,
        "note_type": t.note_type,
        "markdown": t.markdown,
    })
```

### 4.1 新建笔记时模板选择

**修改文件：`ai-interview-frontend/src/views/LearningNoteEdit.vue`**

  <div v-if="!isEditMode && !templateSelected" class="template-selector">

<script setup>
import { ref } from 'vue'
import { getTemplates, getTemplateDetail } from '../api/learningNote'

const templates = ref([])
const templateSelected = ref(false)

async function loadTemplates() {
  if (isEditMode.value) {
    templateSelected.value = true
    return
  }
  try {
    const res = await getTemplates()
    templates.value = res.templates || []
  } catch (e) {
    console.error(e)
    templateSelected.value = true
  }
}

async function selectTemplate(t) {
  try {
    const res = await getTemplateDetail(t.id)
    if (res.markdown) {
      form.value.content = res.markdown
      form.value.note_type = res.note_type || 'note'
    }
    templateSelected.value = true
  } catch (e) {
    templateSelected.value = true
  }
}

function selectBlank() {
  templateSelected.value = true
}

onMounted(loadTemplates)
</script>
