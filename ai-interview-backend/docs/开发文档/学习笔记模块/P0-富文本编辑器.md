# P0 · 富文本编辑器改造

> 优先级：P0 | 预估工时：3-4 天 | 涉及端：前端 + 后端（图片上传）

---

## 1. 背景与目标

### 当前问题
- `LearningNoteEdit.vue` 使用纯 `textarea` 输入 Markdown 源码
- 用户无法实时预览，需要切换页面查看效果
- 不支持粘贴图片，无法插入代码块、表格等
- 对非技术用户门槛高，降低笔记创作意愿

### 目标
- 替换为所见即所得（WYSIWYG）Markdown 编辑器
- 支持工具栏（标题/加粗/列表/代码块/引用/图片/表格）
- 支持实时预览（分屏模式）
- 支持粘贴板直接粘贴图片（自动上传到后端）
- 支持代码语法高亮（面试题高频场景）

---

## 2. 技术选型

### 前端编辑器：`bytemd` + `@bytemd/plugin-gfm`

选择理由：
- 基于 Vue 3 生态，已有 `@bytemd/vue-next` 官方 Vue 3 绑定
- 轻量（gzip ~15KB），不引入重 UI 框架
- 支持 GFM 扩展（表格、任务列表、删除线）
- 插件系统丰富，可扩展图片上传、代码高亮
- 已有项目使用 `marked` 做渲染，`bytemd` 底层也是 `marked`，渲染结果一致

## 3. 后端实现

### 3.1 新增图片上传接口

**文件：`app/api/client/v1/learning_note.py`**

```python
from fastapi import UploadFile, File
import uuid
import mimetypes

@router.post("/upload-image")
async def upload_note_image(
    file: UploadFile = File(...),
    current_user: User = Depends(get_current_user),
):
    """上传笔记中的图片，返回可访问的 URL"""
    # 校验文件类型
    allowed_types = {"image/jpeg", "image/png", "image/gif", "image/webp", "image/svg+xml"}
    content_type = file.content_type or "application/octet-stream"
    if content_type not in allowed_types:
        raise ValidationError(message=f"不支持的文件类型: {content_type}")

    # 读取文件内容
    content = await file.read()
    if len(content) > 5 * 1024 * 1024:  # 5MB 限制
        raise ValidationError(message="图片大小不能超过 5MB")

    # 上传到 S3（复用现有 S3Handler）
    from app.utils.utils import S3Handler
    s3 = S3Handler(settings.AWS_S3_BUCKET)

    # 生成唯一文件名
    ext = mimetypes.guess_extension(content_type) or ".png"
    filename = f"notes/{current_user.id}/{uuid.uuid4().hex}{ext}"

    # 写入临时文件上传
    import tempfile
    with tempfile.NamedTemporaryFile(delete=False, suffix=ext) as tmp:
        tmp.write(content)
        tmp_path = tmp.name

    try:
        url = s3.upload_file(tmp_path, filename)
        return ApiResponse.success(data={"url": url})
    finally:
        os.unlink(tmp_path)
```

## 4. 前端实现

### 4.1 替换编辑页的 textarea → bytemd

**文件：`ai-interview-frontend/src/views/LearningNoteEdit.vue`**

```vue
<template>
  <!-- 删除原来的 textarea，替换为 -->
  <div class="editor-wrapper">
    <Editor
      :value="form.content"
      :plugins="plugins"
      @change="handleEditorChange"
      :uploadImages="handleUploadImages"
      :editorConfig="editorConfig"
    />
  </div>
</template>

<script setup>
import { Editor, Viewer } from '@bytemd/vue-next'
import gfm from '@bytemd/plugin-gfm'
import highlight from '@bytemd/plugin-highlight'
import 'bytemd/dist/index.css'
import 'highlight.js/styles/github-dark.css'

// 导入图片上传 API
import { uploadNoteImage } from '../api/learningNote'

const plugins = [
  gfm(),
  highlight(),
]

const editorConfig = {
  placeholder: '用 Markdown 记录你的学习内容...',
  minHeight: '500px',
  // 自动保存节流
}

async function handleUploadImages(files) {
  // 批量上传图片，返回 { url, alt, title }[] 供 bytemd 插入
  const results = []
  for (const file of files) {
    try {
      const res = await uploadNoteImage(file)
      results.push({
        url: res.url,
        alt: file.name,
        title: file.name,
      })
    } catch (e) {
      console.error('图片上传失败:', e)
    }
  }
  return results
}

function handleEditorChange(v) {
  form.value.content = v
}
</script>

<style scoped>
.editor-wrapper {
  border: 1px solid rgba(255,255,255,0.1);
  border-radius: 10px;
  overflow: hidden;
}
/* 深色主题适配 */
.editor-wrapper :deep(.bytemd) {
  background: rgba(255,255,255,0.05);
  color: var(--text-primary);
  border: none;
}
.editor-wrapper :deep(.bytemd-toolbar) {
  background: rgba(255,255,255,0.08);
  border-bottom: 1px solid rgba(255,255,255,0.1);
}
.editor-wrapper :deep(.bytemd-status) {
  color: var(--text-muted);
}
</style>
```
