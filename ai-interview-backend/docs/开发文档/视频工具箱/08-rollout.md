# 视频工具箱上线与回滚

## 1. 功能开关

- `media_toolbox_enabled`：默认关闭，仅内部管理员和灰度用户可见。
- `media_toolbox_p0_enabled`：控制视频转换、压缩、提取音频、音频转换。
- `media_toolbox_p1_enabled`：控制 GIF、合并、水印。
- `media_url_import_enabled`：默认关闭，不得由普通配置直接打开。

## 2. 放量计划

1. 本地和测试环境：样例文件全量回归。
2. 内部账号：10 个账号，观察成功率、队列和磁盘。
3. 5% 用户：持续 24 小时，成功率不低于 95%，无越权下载。
4. 25% 用户：持续 48 小时，p95 和资源消耗无明显恶化。
5. 全量：保留开关和快速关闭能力。

## 3. 回滚

- 应用层问题：关闭对应功能开关，保留已完成结果下载。
- Worker 问题：停止接收新任务，等待或取消未开始任务，修复后重试失败任务。
- 数据模型问题：先关闭创建接口，再按 Alembic 逆向迁移方案回退。
- 对象存储异常：禁止继续上传，保留任务元数据并在恢复后补偿。

## 4. 数据清理

每日清理超过保留期限的输入和输出文件；数据库只保留审计所需元数据。清理任务必须幂等，失败后可重复执行。
