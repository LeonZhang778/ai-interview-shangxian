# 视频工具箱风险登记

| 风险 | 触发信号 | 应对 | 负责人 |
|---|---|---|---|
| FFmpeg 资源占满 | CPU/内存/队列持续升高 | 限制并发、超时、单任务资源和文件大小 | 后端 |
| 任意参数注入 | 日志出现异常参数或命令失败激增 | 参数白名单，禁止 shell 拼接 | 后端/安全 |
| 文件越权下载 | 403 告警增加 | 任务所有权校验和短时效 URL | 后端/安全 |
| 临时文件泄露 | 过期文件数量增长 | 定时清理、最小权限目录、隔离 Worker | 运维 |
| URL 下载 SSRF | 请求内网或非 HTTP 地址 | 首期关闭，专项设计后再开放 | 安全 |
| 格式兼容性不足 | 某格式失败率高 | 样例矩阵、FFprobe 探测、降级策略 | 后端 |
| 结果不可播放 | 完成后下载失败或播放器无法读取 | 输出探测和抽样播放校验 | 测试 |
| 版权和滥用 | 批量下载或异常流量 | 限额、审计、关闭 URL 导入 | 产品/安全 |

## 触发后的处理原则

先关闭对应功能开关，保留任务和审计证据，再定位 Worker、存储或参数问题。不要通过直接修改生产任务状态掩盖失败。
