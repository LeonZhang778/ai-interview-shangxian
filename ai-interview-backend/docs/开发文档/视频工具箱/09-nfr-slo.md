# 视频工具箱非功能需求

## 性能与容量

- 创建任务接口 p95 小于 500ms。
- 状态查询接口 p95 小于 300ms。
- 单用户同时运行任务数默认不超过 2 个，全局并发通过 Celery 队列控制。
- 首期单文件大小、时长、磁盘配额必须配置化，不能硬编码在前端。
- FFmpeg 任务必须有超时、内存、CPU 和临时目录限制。

## 安全

- 校验扩展名、MIME、FFprobe 探测结果三者一致性。
- 文件名只作为展示字段，存储 key 使用 UUID。
- 仅允许白名单格式、编码器、码率、分辨率、帧率和滤镜参数。
- 下载地址短时效、绑定用户和任务，禁止目录遍历。
- URL 下载默认关闭；如未来开放，必须限制协议、域名、重定向、内网地址和响应大小。
- 上传文件进入隔离目录，必要时接入病毒扫描。

## 可用性与恢复

- 任务状态持久化，Worker 重启后可恢复或明确失败。
- Redis 只做队列和短期进度缓存，数据库是任务状态最终来源。
- 结果文件上传对象存储失败时不得标记完成。

## 可访问性与国际化

- 上传、开始、取消、下载、重试操作支持键盘和焦点态。
- 错误信息提供中文业务说明，保留稳定错误码供前端国际化。
- 前端复用当前项目语言和主题机制，不迁移来源项目 locale 文件。
