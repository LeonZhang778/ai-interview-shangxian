# 视频工具箱复用与重构清单

## 1. 可直接复用的知识和规则

| 来源 | 可复用内容 | 复用方式 |
|---|---|---|
| `项目1/electron/main.ts` | FFmpeg/FFprobe 初始化和系统路径探测思路 | 改写为 Python 配置和 Worker 启动检查 |
| `electron/main.ts:995-1126` | 视频格式对应的视频/音频编码映射 | 抽取为 Python 常量和 Pydantic 校验器 |
| `electron/main.ts:1435-1490` | 提取音频编码映射 | 抽取为服务端格式策略 |
| `electron/main.ts:1522-1560` | 音频转换逻辑 | 改写成安全命令参数列表 |
| `electron/main.ts:1242` | 合并任务输入顺序 | 改为对象存储临时文件 concat 流程 |
| `VideoCompress.vue` | 速度/清晰度/质量三类压缩意图 | 后端转码 preset 白名单 |
| `VideoToGif.vue` | 起止时间、帧率、缩放比例 | 后端范围校验和 GIF 任务参数 |
| `server/index.ts:2651-2892` | 上传、创建任务、任务名称和进度模型 | 仅复用业务流程，不复用 Express 代码 |

## 2. 必须重构的内容

- Electron IPC：改为 FastAPI REST + Celery。
- `Map<string, FfmpegCommand>` 内存任务：改为数据库任务记录、Redis/Celery 执行和可恢复状态。
- 本地绝对路径：改为临时工作目录和对象存储 key。
- 原页面的 Pinia file store：改为当前 Vue 项目的 API composable/store，页面独立设计。
- 原 Web 端轮询：改为统一任务查询，可选 SSE；第一版仍可轮询。
- 原 MySQL 用户中心：使用当前 PostgreSQL 用户和 JWT，不迁移账号表。
- 原 `console.error` 和原始错误：改为结构化日志、业务错误码和脱敏。
- 原会员额度：接入当前项目的设置和用户策略，不复制硬编码额度。

## 3. 不建议复用的内容

- `generateMachineCode`：涉及硬件指纹和隐私，网站不需要。
- Electron `selectFiles`、`selectFolder`、窗口最小化/最大化/关闭：属于桌面容器。
- 外部登录、会员支付、广告、更新器、二维码上传：与当前产品边界不同。
- 原页面 SVG、主题、品牌名和国际化文案：前端页面要求重新设计。
- 原 URL/M3U8 下载：存在 SSRF、版权、协议解析和资源滥用风险。
- 移除水印：需要专项安全和内容合规评估，不能作为首批功能。

## 4. 迁移顺序

1. 抽取格式白名单、编码兼容性和参数范围。
2. 建立媒体文件和任务模型。
3. 实现 FFmpeg Worker 和进度上报。
4. 接入上传、任务查询、下载接口。
5. 接入 P0 前端页面。
6. 以真实样例回归后，再加入合并和水印。
