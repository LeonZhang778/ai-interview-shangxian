# 视频工具箱权限矩阵

## 1. 角色

- `user`：普通登录用户，只能操作自己的文件和任务。
- `admin`：后台管理员，可查询、终止和重试任务，但不默认读取用户媒体内容。
- `system_worker`：仅由 Celery Worker 使用，不作为 HTTP 用户角色。

## 2. 权限

| 资源/动作 | user | admin | system_worker |
|---|---:|---:|---:|
| 上传媒体文件 | ✅ 自己 | ✅ 调试用途 | ❌ |
| 创建媒体任务 | ✅ 自己 | ✅ | ❌ |
| 查看自己的任务 | ✅ | ✅ | ❌ |
| 查看他人任务 | ❌ | ✅ 元数据 | ❌ |
| 下载自己的结果 | ✅ | ✅ | ❌ |
| 读取原始媒体内容 | 仅任务处理间接使用 | 默认 ❌ | ✅ 临时授权 |
| 取消自己的任务 | ✅ pending/processing | ✅ | ❌ |
| 重试失败任务 | ❌ | ✅ | ❌ |
| 修改任务状态 | ❌ | 受限 | ✅ |
| 删除过期文件 | ❌ | ✅ 仅运维 | ✅ |

## 3. 属性规则

- 所有客户端查询附带 `user_id=current_user.id` 条件，禁止仅按任务 ID 查询。
- 管理员接口默认返回文件名、大小、状态和错误码，不返回下载地址，除非明确授权。
- Worker 使用短时效内部任务凭证或数据库任务所有权，不接受浏览器直接调用。
