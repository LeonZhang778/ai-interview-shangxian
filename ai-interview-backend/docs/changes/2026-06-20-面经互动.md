## 一、功能概述

为面经广场添加互动功能，包括：

- **点赞/取消点赞**：用户可对面经点赞，toggle 模式（再次点击取消）
- **收藏/取消收藏**：用户可收藏面经，toggle 模式
- **评论系统**：支持发表评论、回复评论（嵌套一级）、删除自己的评论
- **互动状态查询**：登录用户可查询自己对某面经的点赞/收藏状态

## 三、数据库表设计

### 3.1 user_likes 表（点赞记录）

```sql
CREATE TABLE IF NOT EXISTS user_likes (
    id SERIAL PRIMARY KEY,
    user_id INTEGER NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    experience_id INTEGER NOT NULL REFERENCES experiences(id) ON DELETE CASCADE,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    updated_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    CONSTRAINT uq_user_like UNIQUE (user_id, experience_id)
);

CREATE INDEX idx_user_likes_user_id ON user_likes(user_id);
CREATE INDEX idx_user_likes_experience_id ON user_likes(experience_id);
```

**设计要点**：

- `uq_user_like` 唯一约束保证同一用户对同一面经只能点赞一次
- 点赞/取消点赞通过 toggle 实现：先查是否存在记录，存在则删除（取消），不存在则添加

### 3.2 experience_comments 表（评论）

```sql
CREATE TABLE IF NOT EXISTS experience_comments (
    id SERIAL PRIMARY KEY,
    experience_id INTEGER NOT NULL REFERENCES experiences(id) ON DELETE CASCADE,
    user_id INTEGER NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    parent_id INTEGER REFERENCES experience_comments(id) ON DELETE CASCADE,
    content TEXT NOT NULL,
    like_count INTEGER DEFAULT 0,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    updated_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

CREATE INDEX idx_experience_comments_experience_id ON experience_comments(experience_id);
CREATE INDEX idx_experience_comments_user_id ON experience_comments(user_id);
CREATE INDEX idx_experience_comments_parent_id ON experience_comments(parent_id);
```

**设计要点**：

- `parent_id` 自引用外键，支持一级嵌套回复（回复的回复不再展开）
- `ON DELETE CASCADE`：父评论删除时自动删除所有子回复
- `like_count` 预留评论点赞字段，当前未实现评论点赞 API

## 四、ORM 模型

### 4.1 UserLike 模型

```python
# app/models/experience.py
class UserLike(BaseModel):
    __tablename__ = "user_likes"

    id = Column(Integer, primary_key=True, index=True, autoincrement=True)
    user_id = Column(Integer, ForeignKey("users.id", ondelete="CASCADE"), nullable=False)
    experience_id = Column(Integer, ForeignKey("experiences.id", ondelete="CASCADE"), nullable=False)

    __table_args__ = (
        UniqueConstraint("user_id", "experience_id", name="uq_user_like"),
    )
```

### 4.2 ExperienceComment 模型

```python
# app/models/experience.py
class ExperienceComment(BaseModel):
    __tablename__ = "experience_comments"

    id = Column(Integer, primary_key=True, index=True, autoincrement=True)
    experience_id = Column(Integer, ForeignKey("experiences.id", ondelete="CASCADE"), nullable=False, index=True)
    user_id = Column(Integer, ForeignKey("users.id", ondelete="CASCADE"), nullable=False)
    parent_id = Column(Integer, ForeignKey("experience_comments.id", ondelete="CASCADE"), nullable=True)
    content = Column(Text, nullable=False)
    like_count = Column(Integer, default=0)

    author = relationship("User", lazy="joined")
    replies = relationship("ExperienceComment", backref="parent", remote_side="ExperienceComment.id", lazy="selectin")
```

**注意**：`replies` 关系使用 `lazy="selectin"`，但在 SQLAlchemy 2.0 async 中自引用关系的 selectinload 存在问题，实际查询时使用手动批量查询回复。

## 六、核心业务逻辑

### 6.1 点赞 Toggle

```python
# app/services/client/experience_service.py
@staticmethod
async def like_experience(db, experience_id, user_id):
    experience = await db.get(Experience, experience_id)
    if not experience or experience.status != "published":
        raise NotFoundError(message="面经不存在")

    result = await db.execute(
        select(UserLike).where(
            UserLike.user_id == user_id,
            UserLike.experience_id == experience_id
        )
    )
    existing = result.scalar_one_or_none()

    if existing:
        await db.delete(existing)
        experience.like_count = max(0, experience.like_count - 1)
        liked = False
    else:
        db.add(UserLike(user_id=user_id, experience_id=experience_id))
        experience.like_count += 1
        liked = True

    await db.commit()
    return {"liked": liked, "like_count": experience.like_count}
```

### 6.2 评论列表（手动查询回复）

由于 SQLAlchemy 2.0 async 中自引用关系的 `selectinload` 存在兼容问题，采用手动批量查询回复的方式：

```python
# app/services/client/experience_service.py
@staticmethod
async def get_comments(db, experience_id, page=1, size=20):
    # 1. 查询顶级评论（parent_id IS NULL）
    query = (
        select(ExperienceComment)
        .where(
            ExperienceComment.experience_id == experience_id,
            ExperienceComment.parent_id.is_(None)
        )
        .options(joinedload(ExperienceComment.author))
        .order_by(ExperienceComment.created_at.desc())
    )
    # ... 分页 ...

    # 2. 批量查询所有回复
    comment_ids = [c.id for c in comments]
    replies_map = {}
    if comment_ids:
        reply_query = (
            select(ExperienceComment)
            .where(ExperienceComment.parent_id.in_(comment_ids))
            .options(joinedload(ExperienceComment.author))
            .order_by(ExperienceComment.created_at.asc())
        )
        reply_result = await db.execute(reply_query)
        for r in reply_result.unique().scalars().all():
            replies_map.setdefault(r.parent_id, []).append(r)

    # 3. 组装结果
    items = []
    for c in comments:
        replies_data = [
            {
                "id": r.id,
                "content": r.content,
                "user": {"id": r.author.id, ...},
                "parent_id": r.parent_id,
                "like_count": r.like_count,
                "created_at": r.created_at.isoformat(),
            }
            for r in replies_map.get(c.id, [])
        ]
        items.append({
            "id": c.id,
            "content": c.content,
            "user": {"id": c.author.id, ...},
            "parent_id": None,
            "replies": replies_data,
            ...
        })

    return {"items": items, "total": total, "page": page, "per_page": size}
```

**为什么不用 `selectinload`**：
SQLAlchemy 2.0 的 async session 对自引用关系的 `selectinload` 支持不完善，`c.replies` 始终返回空列表。改用手动查询 + Python 字典映射的方式可靠地加载嵌套回复。

### 6.3 评论权限控制

```python
@staticmethod
async def delete_comment(db, comment_id, user_id):
    comment = await db.get(ExperienceComment, comment_id)
    if not comment:
        raise NotFoundError(message="评论不存在")
    if comment.user_id != user_id:
        raise AuthorizationError(message="只能删除自己的评论")
    await db.delete(comment)
    await db.commit()
```
