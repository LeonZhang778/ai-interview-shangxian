# 2026-06-21 面经体验优化：浅色主题修复 + Markdown升级 + 管理增强

## 1. 功能说明

本次改动针对上一轮上线后发现的问题进行修复和增强，共 5 项：

1. **浅色主题标题不可见**：面经详情页标题和面包屑栏颜色硬编码为白色/深色，切换浅色主题后看不见。改为 CSS 变量适配。
2. **Markdown 渲染升级**：投稿页预览和详情页正文渲染从简单正则替换改为使用 `marked` 库，支持 GFM（表格、任务列表）、代码块语法高亮、嵌套格式等。
3. **投稿文件导入**：投稿页新增"导入"按钮，支持上传 `.txt` / `.md` 文件读取内容到编辑器，同时新增字数统计和标题格式化快捷按钮。
4. **面经删除功能**：管理后台面经管理页面新增单条删除按钮，支持删除任意状态的面经。
5. **批量审核**：管理后台新增复选框列，支持全选/多选后批量通过、批量拒绝、批量删除。

## 2. 涉及路由

### 新增接口

| 方法 | 路径 | 说明 | 鉴权要求 |
|------|------|------|----------|
| DELETE | `/api/v1/backoffice/experiences/{id}` | 删除面经 | 需管理员 |
| POST | `/api/v1/backoffice/experiences/batch-review` | 批量审核/删除 | 需管理员 |

请求体示例（batch-review）：
```json
{"ids": [1, 2, 3], "action": "approve"}
```
action 可选值：`approve`、`reject`、`delete`

## 3. 核心实现逻辑

### Markdown 渲染

引入 `marked` 库（42KB gzip 12KB），配置 `breaks: true` + `gfm: true`，替换原有正则方案。投稿页预览和详情页共用同一套配置。

```js
import { marked } from 'marked'
marked.setOptions({ breaks: true, gfm: true })
// 使用：marked.parse(text)
```

### 文件导入

使用 FileReader API 读取用户选择的 `.txt` / `.md` 文件内容，直接填入 textarea：

```js
function handleFileImport(event) {
  const file = event.target.files[0]
  const reader = new FileReader()
  reader.onload = (e) => { form.content = e.target.result }
  reader.readAsText(file)
}
```

### 批量审核

前端通过 `selectedIds` 数组记录勾选的面经 ID，批量操作时调用 `POST /batch-review`。后端遍历 ID 列表逐条处理（approve/reject/delete），统一 commit。

### 浅色主题修复

将 `ExperienceDetail.vue` 中硬编码的 `color: #f8fafc` 改为 `var(--text-primary)`，`background: rgba(8,5,25,0.8)` 改为 `var(--bg-surface)`。

## 4. 数据库设计

无表结构变更。复用已有 `experiences` 表。
