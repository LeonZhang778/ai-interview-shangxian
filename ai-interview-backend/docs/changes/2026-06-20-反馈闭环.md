# 反馈闭环功能开发文档

> 日期：2026-06-20
> 功能：用户反馈闭环 — 用户可查看自己的反馈及管理员回复

---

## 一、功能说明

当前反馈系统是单向的：用户提交反馈后无法看到管理员的回复。本次改动补上闭环：

1. **提交反馈时记录用户 ID**：已登录用户提交反馈时自动关联 `user_id`，游客仍可提交（`user_id` 为 null）
2. **用户查看自己的反馈**：已登录用户可查看自己提交的所有反馈列表，包括管理员回复内容和处理状态
3. **前端"我的反馈"页面**：在个人中心入口展示反馈历史

---

## 三、核心实现逻辑

### 3.1 提交反馈 — 自动关联用户

当前 `submit_feedback` 不接收用户信息。改为：如果请求带了 JWT token，自动解析并记录 `user_id`；没有 token 也能提交（游客模式）。

调用链路：请求进入 `feedback.py` → 通过可选依赖 `get_current_user_optional` 尝试解析 token → 解析成功则记录 `user_id`，失败则为 null → 写入 `feedbacks` 表。

```python
# 新增可选认证依赖
async def get_current_user_optional(
    token: str = Depends(OAuth2PasswordBearer(tokenUrl="...", auto_error=False)),
    db: AsyncSession = Depends(get_db),
) -> Optional[User]:
    if not token:
        return None
    payload = AuthBase.verify_token(token, scope="client")
    if not payload:
        return None
    user = await db.get(User, int(payload.get("sub")))
    return user if user and user.is_active else None
```

### 3.2 查询我的反馈

调用链路：请求进入 `feedback.py` → 校验登录（`get_current_user`）→ 按 `user_id` 查询 `feedbacks` 表 → 按 `created_at` 降序返回 → 包含 `admin_reply` 和 `status`。
