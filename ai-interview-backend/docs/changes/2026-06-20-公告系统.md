# 公告系统（Announcement）

> 日期：2026-06-20
> 涉及模块：后端 API、数据库、管理后台前端、用户端前端

---

## 1. 功能说明

新增公告系统，支持管理员在后台发布、管理公告，用户端以全局横幅形式展示。面向两类角色：

**管理员**：在后台创建/编辑/删除公告，设置类型（通知/更新/维护/活动）、优先级（P0 紧急/P1 重要/P2 普通）、置顶、上下线、定时发布、过期时间。

**用户**：在前台顶部看到公告横幅，按 P0→P1→P2 排序展示。P0 红色不可关闭，P1 蓝色可关闭，P2 灰色可关闭。多条公告自动轮播（5 秒），支持 ESC 键关闭，关闭状态通过 localStorage 缓存 24 小时。

## 2. 涉及路由

### 用户端 API（无需认证）

| 方法 | 路径 | 说明 | 鉴权 |
|------|------|------|------|
| GET | `/api/v1/announcements` | 分页获取有效公告列表 | 无 |
| GET | `/api/v1/announcements/latest` | 获取最新一条公告 | 无 |
| GET | `/api/v1/announcements/{id}` | 获取公告详情 | 无 |

查询逻辑（三个接口共用）：
- `is_active = True`
- `published_at <= now` 或 `published_at IS NULL`
- `expired_at > now` 或 `expired_at IS NULL`
- 排序：`level ASC`（P0 在前） → `is_pinned DESC` → `published_at DESC`

### 管理后台 API（需管理员 JWT）

| 方法 | 路径 | 说明 | 鉴权 |
|------|------|------|------|
| GET | `/api/v1/backoffice/announcements` | 分页列表（支持按类型/状态筛选） | 管理员 |
| POST | `/api/v1/backoffice/announcements` | 创建公告 | 管理员 |
| PUT | `/api/v1/backoffice/announcements/{id}` | 编辑公告 | 管理员 |
| DELETE | `/api/v1/backoffice/announcements/{id}` | 删除公告 | 管理员 |
| PUT | `/api/v1/backoffice/announcements/{id}/pin` | 切换置顶状态 | 管理员 |
| PUT | `/api/v1/backoffice/announcements/{id}/status` | 切换上线/下线 | 管理员 |

## 3. 核心实现逻辑

### 3.1 用户端查询 — 三重过滤 + 优先级排序

所有用户端接口共用同一套过滤条件：只返回"当前有效"的公告。`_serialize()` 统一序列化字段。

```python
# app/api/client/v1/announcement.py

def _serialize(a):
    return {
        "id": a.id,
        "title": a.title,
        "content": a.content,
        "type": a.announcement_type,
        "level": a.level or "P1",
        "is_pinned": a.is_pinned,
        "published_at": a.published_at.isoformat() if a.published_at else a.created_at.isoformat(),
    }

# 三重过滤 + 排序（GET /、/latest、/{id} 共用）
now = datetime.now(timezone.utc)
query = (
    select(Announcement)
    .where(Announcement.is_active == True)                                    # 已上线
    .where(or_(Announcement.published_at.is_(None), Announcement.published_at <= now))  # 已到发布时间
    .where(or_(Announcement.expired_at.is_(None), Announcement.expired_at > now))       # 未过期
    .order_by(
        Announcement.level.asc(),          # P0(0) < P1(1) < P2(2)
        Announcement.is_pinned.desc(),     # 置顶优先
        Announcement.published_at.desc()   # 最新优先
    )
)
```

**设计决策**：排序用 `level ASC` 而不是 `DESC`，因为 level 值是字符串 "P0"/"P1"/"P2"，字典序刚好 P0 < P1 < P2，符合"紧急优先"的业务语义。

### 3.2 后台管理 — 创建/编辑用 Query 参数

后台的 POST 和 PUT 接口使用 FastAPI 的 Query 参数而非 JSON Body，这是因为前端通过 `params` 传递数据：

```python
# app/api/backoffice/v1/announcement.py

@router.post("")
async def create_announcement(
    title: str,                          # Query 参数
    content: str,
    announcement_type: str = "info",
    level: str = "P1",
    is_pinned: bool = False,
    published_at: Optional[str] = None,  # ISO 格式字符串
    expired_at: Optional[str] = None,
    db: AsyncSession = Depends(get_db),
    current_admin: Admin = Depends(get_current_admin)
):
    announcement = Announcement(
        title=title, content=content,
        announcement_type=announcement_type, level=level,
        is_pinned=is_pinned, is_active=True,
        published_at=datetime.fromisoformat(published_at) if published_at else datetime.now(timezone.utc),
        expired_at=datetime.fromisoformat(expired_at) if expired_at else None,
        created_by=current_admin.id,
    )
    db.add(announcement)
    await db.commit()
```

### 3.3 前台横幅组件 — 轮播 + localStorage 缓存

`AnnouncementBanner.vue` 是全局组件，挂在 `App.vue` 的顶部。核心逻辑：

**数据加载**：`onMounted` 时调用 `getAnnouncements({page:1, size:10})`，过滤已关闭的公告（localStorage 比对），按 level 排序后赋值。

**轮播**：多条公告时每 5 秒自动切换 `currentIndex`，用户点击指示器手动切换时重置计时器。

**关闭缓存**：localStorage 存 `{id, version, closedAt}`，`version` 用 `published_at` 做版本控制（公告更新后重新展示），24 小时后自动失效。

```javascript
// localStorage key: announcement_closed
// 存储格式: {id: 公告id, version: published_at, closedAt: Date.now()}
function isClosed(announcement) {
    const saved = JSON.parse(localStorage.getItem('announcement_closed') || '{}')
    if (saved.id === announcement.id && saved.version === announcement.published_at) {
        const elapsed = Date.now() - (saved.closedAt || 0)
        if (elapsed < 24 * 60 * 60 * 1000) return true  // 24小时内关闭过
    }
    return false
}
```

**等级样式**：

| 等级 | 背景 | 关闭按钮 | 图标 |
|------|------|---------|------|
| P0 | 红色渐变 | 无（不可关闭） | 警告三角 |
| P1 | 蓝色渐变 | 有 | 信息圆圈 |
| P2 | 灰色渐变 | 有 | 铃铛 |

## 4. 数据库设计

### 新增表：`announcements`

| 字段 | 类型 | 可空 | 默认值 | 说明 |
|------|------|------|--------|------|
| id | SERIAL | NOT NULL | 自增主键 | |

| expired_at | TIMESTAMP WITH TIME ZONE | NULL | — | 过期时间（NULL=永不过期） |
| created_by | INTEGER | NOT NULL | — | 外键 → admins.id |
| created_at | TIMESTAMP WITH TIME ZONE | NOT NULL | now() | 继承自 BaseModel |
| updated_at | TIMESTAMP WITH TIME ZONE | NOT NULL | now() | 继承自 BaseModel |
