# 面试报告分享功能

## 1. 功能说明

用户完成面试后，可以生成一个公开的分享链接，将链接发给朋友即可查看面试评估报告。分享链接无需登录即可访问，方便用户展示面试表现并为平台引流。支持生成链接、复制链接、取消分享等操作。

## 2. 涉及路由

| 方法 | 路径 | 说明 | 鉴权要求 |
|------|------|------|---------|
| POST | `/api/v1/interviews/{id}/share` | 生成分享链接 | 需登录 |
| DELETE | `/api/v1/interviews/{id}/share` | 取消分享 | 需登录 |
| GET | `/api/v1/shared/{token}` | 查看分享报告 | 不需要 |

## 3. 核心实现逻辑

请求链路：
- 生成分享：`POST /interviews/{id}/share` → `interview_service.share_interview()` → 生成 `secrets.token_urlsafe(24)` 作为分享 token → 更新 Interview 记录的 `share_token`、`is_shared`、`shared_at` → 返回 token
- 查看分享：`GET /shared/{token}` → `interview_service.get_shared_report()` → 根据 token 查询 Interview → 返回脱敏的报告数据（不暴露 user_id 等敏感信息）
- 取消分享：`DELETE /interviews/{id}/share` → 清空 share_token 和 is_shared

核心代码片段 - 生成分享 token：
```python
interview.share_token = secrets.token_urlsafe(24)[:32]
interview.is_shared = True
interview.shared_at = datetime.utcnow()
```

核心代码片段 - 获取分享报告（公开接口，不暴露用户信息）：
```python
return {
    "interview_id": interview.id,
    "overall_score": float(interview.overall_score) if interview.overall_score else 0,
    "total_questions": interview.total_questions,
    "target_position": interview.target_position,
    "difficulty": interview.difficulty,
    "created_at": interview.created_at.isoformat() if interview.created_at else None,
    "report": report
}
```

## 4. 数据库设计

修改 `interviews` 表，新增 3 个字段：

| 字段 | 类型 | 是否可空 | 默认值 | 说明 |
|------|------|---------|--------|------|
| `share_token` | String(32) | 是 | NULL | 分享链接 token，唯一索引 |
| `is_shared` | Boolean | 否 | false | 是否已分享 |
| `shared_at` | TIMESTAMP | 是 | NULL | 分享时间 |
