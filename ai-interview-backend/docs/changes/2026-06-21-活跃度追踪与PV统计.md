# 2026-06-21 活跃度追踪与PV统计 + 匿名用户复用

## 1. 功能说明

本次改动修复 3 个问题：

1. **DAU 统计不准**：原来 DAU 只统计当天创建面试的用户数，登录但未创建面试的用户不计入。改为基于 `last_active_at` 字段统计，通过中间件自动更新用户活跃时间。
2. **无页面访问量统计**：系统完全没有 PV/UV 追踪。新增 `page_views` 表和追踪接口，前端通过 `navigator.sendBeacon` 在每次路由切换时上报。
3. **匿名用户无限累积**：每次点击"游客模式"都会创建新的匿名用户。改为前端检查 localStorage 已有 guest token 时直接复用，不再调用 `/auth/guest`。同时新增管理后台游客清理接口。

## 3. 核心实现逻辑

### 活跃度追踪中间件

新增 `ActivityTrackingMiddleware`，对所有客户端 API 请求：
1. 提取 Authorization header 中的 JWT
2. 解码获取 user_id
3. 用 Redis 节流（key: `activity:{user_id}`，TTL 5 分钟）
4. 节流通过则异步更新 `users.last_active_at = NOW()`

```python
class ActivityTrackingMiddleware(BaseHTTPMiddleware):
    async def dispatch(self, request, call_next):
        response = await call_next(request)
        # 提取 token → 解码 → Redis 节流 → 更新 last_active_at
        return response
```

### 页面浏览追踪

- 新增 `page_views` 表（user_id, session_id, page_path, created_at）
- 前端 `utils/tracker.js`：生成 24h 有效的 session_id 存入 localStorage，通过 `sendBeacon` 上报
- Vue Router `afterEach` 钩子自动触发上报
- 后端 `BackgroundTasks` 异步写入 DB，不阻塞响应

### 匿名用户复用

前端 `handleGuest()` 增加判断：
```javascript
if (authStore.isLoggedIn && authStore.isGuest) {
  router.push('/dashboard')  // 直接复用已有 token
  return
}
```

### 游客清理

管理后台新增 `DELETE /users/guests/cleanup?days=30`，删除超过 N 天未活跃的游客用户及其 token。

## 4. 数据库设计

### 新增表：page_views

```sql
CREATE TABLE page_views (
    id SERIAL PRIMARY KEY,
    user_id INTEGER,
    session_id VARCHAR(64),
    page_path VARCHAR(512) NOT NULL,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW() NOT NULL,
    updated_at TIMESTAMP WITH TIME ZONE DEFAULT NOW() NOT NULL
);
CREATE INDEX ix_page_views_user_id ON page_views(user_id);
CREATE INDEX ix_page_views_session_id ON page_views(session_id);
CREATE INDEX ix_page_views_created_at ON page_views(created_at);
```
